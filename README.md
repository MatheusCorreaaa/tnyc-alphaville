# The New York Coffee – Alphaville

Site da unidade Rio Negro em Alphaville, Barueri. A página apresenta a animação do café, o cardápio com fotos e preços, as avaliações de clientes e as informações para visita.

## Executar localmente

Na raiz do repositório, rode:

```sh
python -m http.server 8000
```

Abra <http://localhost:8000>. O site usa HTML, CSS e JavaScript e dispensa uma etapa de build.

## Atualizar o cardápio

Edite os produtos e preços em `app.js`. As fotografias e o PDF ficam em `assets/`.
